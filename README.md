# FUNDAMENTOS-HTML-SEGUNDO-SEMESTRE
Exercícios, projetos práticos  e atividades de desenvolvimento Web (HTML/CSS) desenvolvidos durante o 2º semestre da faculdade ( UNICSUL )

📚 Web Development & Front-End Studies
Bem-vindo(a) ao repositório dedicado aos meus estudos de Desenvolvimento Web e Front-End! Este projeto serve como um diário de aprendizado prático, documentando a evolução do aprendizado de conceitos fundamentais até o desenvolvimento de aplicações completas.

📌 Sobre o Repositório
O objetivo deste repositório é armazenar códigos, exercícios, projetos acadêmicos e práticas desenvolvidas ao longo das disciplinas e estudos autodidatas de desenvolvimento web.

A estrutura é organizada de forma progressiva, acompanhando a evolução nas seguintes áreas:

Estruturação Web: HTML5 semântico, acessibilidade e boas práticas.

Estilização & Design: CSS3, CSS Responsive, Flexbox, Grid Layout e Frameworks.

Lógica & Interatividade: JavaScript (ES6+), manipulação da DOM e APIs.

Projetos Integrados: Interfaces para portais, sistemas web e protótipos funcionais.
